# Rock Paper Scissors Game 🎮

A simple and fun **Rock, Paper, Scissors** game built using **HTML, CSS, and JavaScript**. You can play against the computer, and the first to reach a certain score wins the game.

## 🌟 Features

- Interactive UI 
- Play against the computer
- Score tracking for both player and computer
